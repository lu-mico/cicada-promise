## 1. 一句话卖点

一个钟表匠用三十年，为三十年前死去的女孩完成一场「让真相被看见」的延时谋杀；而读者直到全书过半才发现——自己一直以为的「现在」，是三十年前。

## 2. 三层欺骗（核心诡计）

1. **第一层（ch1–9）**：A 线舆论让读者相信「夏晓晓是畏罪潜逃的凶手」。
2. **第二层（ch8–10）**：B 线揭示「夏晓晓是受害者，且三十年前已死」→ 读者发现自己被骗。
3. **第三层（ch11–15）**：真凶是一直站在读者面前、最不可能的林默；而他的动机不是复仇，是爱。

## 3. 视角与叙述框架（定稿）

| 线 | 视角 | 说明 |
|----|------|------|
| A 线 2026 | 周睿（第一人称） | 冷静、职业、被真相层层击穿 |
| B 线 1996 | 夏晓晓（第一人称） | 炽热、青春；ch8–10 死亡揭示后转为「亡者叙述」直至终章 |
| 终章 ch20 | 林默（第一人称） | 全书唯一一次 → 最大冲击 |

**叙述规则（防穿帮）：**
- 晓晓的亡者叙述只「看见」、不理解：机械、化学、法律程序一律不懂 → 谜底由 A 线周睿解开，双线各持一半真相。
- 全书禁止出现第三人称全知段落；周睿线不得知道 B 线内容，晓晓线不得知道 A 线内容。

## 4. 时间轴（最终版）

- **1996 春–夏**：相遇 → 欺凌 → 胸针 → 夏家破 → 林默重伤
- **1996 夏末**：夏母携晓晓离镇求医；林默伤愈后寻访
- **1997**：晓晓死于外地，安葬外地；林默在葬仪之外见白布，立誓
- **1997–2026**：学机械/化学 → 开钟表铺 → 每年忌日祭拜，从不缺席
- **2026 夏**：张扬回乡开发 → 密室延时机关 → 胸针留在现场 → 周睿追查 → 自白 → 审判
- 全程恰好 30 年 → 「蝉的十七年」对照成立

**防漏规则（写手检查清单）：**
1. B 线绝不出现：年份数字、智能手机、网络、现代品牌、明确岁数变化。
2. B 线可用：固定电话、书信、旧自行车、灯塔、钟表、无品牌校服。
3. A 线科技感拉满（社媒头条、监控、电子档案）→ 与 B 线形成落差但不点破。
4. 「三十年前」一词首次出现必须 ≥ ch8，且不得与林默同句。
5. 每章 B 线场景限定无科技场景（学校、灯塔、病房、家）——「小镇的慢」掩护年代。
6. 媒体污名：2026 年报道把晓晓写成张扬「前女友」→ 呼应主题「当真相被重复一千遍，它就会变成谎言」。

## 6. 道具与伏笔清单

- **蝉蜕胸针**：信物 → 战利品 → 证物 → 署名（四重身份，贯穿全书）
- **灯塔**：相遇处 / 约定处 / 对峙处
- **钟表**：林默的身份、技术、不在场证明、时间隐喻
- **蝉**：十七年蛰伏 vs 三十年等待
- **「永远」**：少年的誓言 vs 三十年的兑现
- **老照片**：1996 年合照 → ch8 物证
- **墓前的花**：三十年不缺席 → 追查线索

## 8. 商业化建议（MSP）

- **体量**：20 章 × 6–8 千字 ≈ 13–16 万字，网文连载或单卷出版皆宜。
- **断章钩子**：每章双线天然留悬念；ch1–3 社媒舆论钩子、ch8/ch10 双爆点。
- **改编向**：密室诡计 + 情感反转，影视化卖点明确；批准后我可出「一页纸企划书」（logline + 章节表 + 卖点）。
- **标题**：主标《夏蝉的诺言》保留；可加副标《蝉鸣三十载》。
