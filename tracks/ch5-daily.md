**档案馆卷（进馆本，薄册＝九六年后半年至九七年底）**

- 抽页痕迹：两个孔、孔边线磨白、翘纤维、箱底干净 → 判定「抽」非「烂」。

**两份迁出（ch2 迁移证明 ＋ 登记簿）**
- ch2 迁移证明（周睿卷宗内）：夏晓晓，女，1979 年生，**1996 年 8 月 12 日**，因家庭原因随母迁出本镇，**目的地不详**。

## 七、每日自检与交付流程（脚本，非目测）

1. 写当日切片 → `manuscripts/ch5-<切片号>.md`（格式照 ch4：标题行 + > 编制/轨道/大纲依据 元信息块 + 正文（## 一 / ## 二 …）+ 文末「## 写作说明」表 + 「## 下一切片」）。
2. `python3 tracks/check.py manuscripts/ch5-<切片号>.md` → **退出码必须为 0**（ERROR=0）。不达标就改到 0 再交。
3. `git add` + `commit -m "Yomi: ch5 <切片号> 切片 — <一句话内容>"` + `git push origin main`。
4. 频道只回报 **commit hash + 一句话内容**；**不手报字数**（字数只认 `tracks/check.py` 的实测与退出码 0）。

> ⚠️ **deslop / detector 门禁必须在项目目录就地跑**（2026-11-05 Mico 踩坑记录）：
> 白名单在 `manuscripts/.deslop-whitelist`，**与稿件同目录**；把文件复制到 `/tmp` 再跑，白名单失效，会**误报 em-dash blocking=18**；回项目目录重跑 = **blocking=0**。以后谁跑这个门禁都别复制文件。

## 八、排期纪律（R35/R36 血训，不可省）

- **21:30 切片后，22:00 必须查两条证据**：① `git log` 有无当日 commit；② `openclaw cron runs --id be2b1e10` 有无当日条目。
  - 两条都缺 = **宿主进程级漏跑**（OpenClaw 进程当时不在位）→ 当场手动 `openclaw cron run be2b1e10` 补跑，不等下一个 21:30。
  - 有条目但 0 commit = 才查选片规则（R33 的 10/30 属此类：候选集为空 → 空跑）。
- `cron list` 的「Next 2m ago」是**下次触发时刻**，不是「lastRun」；「Last」栏才是上一轮。
- ⚠️ **巡检时点必须晚于切片槽**：切片 cron 在 **21:30**，巡检在 **20:00**——巡检查「当日 commit」时，当天的切片窗口**还没开**，正常一天也会是 0。**R39（11/06 20:00）误判「A1 没接上」即由此而来**：下一场 A1 的正常交付时间是**当晚 21:30**，不是明晚。判据改为：**22:05 之后**才查当日产出（21:30 槽 + 135s 运行时长已过）。
- 📌 **22:05 自动验收已上线（R39 新增）**：cron job `9f6e770e`（ch5 slice verify 22:05，`5 22 * * *` Asia/Tokyo，command payload 跑 `tracks/verify_daily_slice.sh`）——21:30 后查两条证据：① `git log` 当日 commit ② `cron runs` 当日条目。两条都缺且下一场切片文件不存在 → **自动补跑 `be2b1e10`**；有条目但 0 commit → 只告警不重跑（防重复交付）；一切正常 → 打印 `NO_REPLY` 静默，不刷频道。**§八 的纪律从此是可执行轨道，不靠自律。**
- **cron「跑过」≠「产出」**：验收必须看 `git log` 有无新 commit，不能看 `lastRunStatus=ok` / `delivered=true`。
- 📌 **R42（2026-11-10 21:50 血训）：「槽被宿主掐掉」也是一种漏跑，error 条目 ≠ 跑过。**
  - 事实：21:50 gateway 重启把 **21:30 切片槽与 22:05 验收槽同时掐断**，两条 `cron runs` 条目都写着 `cron: job interrupted by gateway restart`（切片槽 runAtIso 21:50:13／验收槽 21:50:11）；Mico 21:55 手动补跑 → 22:04 交 `7c2df68`（B3），22:06 验收槽恢复后回 NO_REPLY。**不是没干活，是被掐。**
  - **旧判据的坑**：验收脚本原来用 `grep -c '"runAtIso": "$TODAY'` 数条目，**error 条目也被算成「有条目」** → 命中「有条目但 0 commit → 只告警不重跑」分支 → 那晚切片会**静默丢失**（比 0 条目更隐蔽）。
