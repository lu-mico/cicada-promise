## 三、唯一事实源（2026-11-05 从 ch4-notes.md §六 抄入，ch5 起沿用）

> 以下为 ch4 裁定并改稿后的事实集。ch5 引用 ch4 的任何事实，**以本节为准**，不得改写、不得另立版本。

**档案馆卷（进馆本，薄册＝九六年后半年至九七年底）**
- 夏家条目：迁入两笔 → 居住变更一笔 → 迁出一笔（**九七年一月**；迁出日期有，迁往地址空）→ 此后**缺一页**（缺的是九七年十月年度核对页）。
- 抽走后迁出之后无任何记载（注销没有、续迁也没有）。
- 抽页痕迹：两个孔、孔边线磨白、翘纤维、箱底干净 → 判定「抽」非「烂」。
- 调阅登记本：九八年起只记过一行（三个星期前那次外单位调阅，登记人小陈；该行日期换算为星期三，而对方回函作星期二，**差一天，该行不能作准**）；九八年初装订检查**只查线、胶、纸边，不核页数**。

**两份迁出（ch2 迁移证明 ＋ 登记簿）**
- ch2 迁移证明（周睿卷宗内）：夏晓晓，女，1979 年生，**1996 年 8 月 12 日**，因家庭原因随母迁出本镇，**目的地不详**。
- 登记簿那一笔：**九七年一月**（与 1996 年 8 月 12 日正好相差五个月），地址同样空。
- 裁定：早的一份是他们走那天办的（原始出证），晚的一份是后来补进册子的；两份都只说搬走，都没说搬到哪儿（与 plan-v2 §0 修订要点 6「本地档案只有全家搬离→误导成立」一致）。
- 处理：另立待查，**不并入本章断点结论**。

**派出所底册（留所本）**
- 同一条目序列 ＋ 那张**九七年十月年度核对页**（页头四字「年度核对」；四栏：户号、在册人数、核对情形、备注；夏家行：在册人数「三」、核对情形「在册」、备注「户主外出，由邻代核」；页脚格线外铅笔「实未迁」）。
- 「三」的构成：夏母、晓晓、父亲（名字后面带一个「故」字）——与 ch2「父亲病故、母亲带晓晓离镇求医」一致；这一户的户口从未销号。
- 后续核对表序列：九八「未见」／九九「未见」／第四年**整行没有**。

**抽页的可查条件**
- 不在档案馆发生（馆内调阅登记九八年起只有那一行）。
- 也不必外借整册（陶师傅证实：九八年十月核账时册子**抱到所里核过**，核完送回）。

## 六、字数口径（唯一定义，脚本实测，非目测）

```bash
python3 tracks/check.py manuscripts/ch5-<切片号>.md
```

- 正文段 = 切片/分线标题行起，到「## 写作说明」之前；不含顶部元信息抬头。
- 字数 = 该段 Unicode 汉字（U+4E00–U+9FFF）个数。
- **每场目标 1,300–1,700 汉字**（收束场可到 1,700）；**每线 ≥ 4,300**（ch5 起，余量纪律）。
- A 线允许出现**档案上的具体年份**（1996／1997），`check.py` 对 A 线年份只报 WARN 不阻断；但**任何年数推算**仍禁止。

## 七、每日自检与交付流程（脚本，非目测）

1. 写当日切片 → `manuscripts/ch5-<切片号>.md`（格式照 ch4：标题行 + > 编制/轨道/大纲依据 元信息块 + 正文（## 一 / ## 二 …）+ 文末「## 写作说明」表 + 「## 下一切片」）。
2. `python3 tracks/check.py manuscripts/ch5-<切片号>.md` → **退出码必须为 0**（ERROR=0）。不达标就改到 0 再交。
3. `git add` + `commit -m "Yomi: ch5 <切片号> 切片 — <一句话内容>"` + `git push origin main`。
4. 频道只回报 **commit hash + 一句话内容**；**不手报字数**（字数只认 `tracks/check.py` 的实测与退出码 0）。

> ⚠️ **deslop / detector 门禁必须在项目目录就地跑**（2026-11-05 Mico 踩坑记录）：
> 白名单在 `manuscripts/.deslop-whitelist`，**与稿件同目录**；把文件复制到 `/tmp` 再跑，白名单失效，会**误报 em-dash blocking=18**；回项目目录重跑 = **blocking=0**。以后谁跑这个门禁都别复制文件。

## 八、排期纪律（R35/R36 血训，不可省）

- **21:30 切片后，22:00 必须查两条证据**：① `git log` 有无当日 commit；② `openclaw cron runs --id be2b1e10` 有无当日条目。
  - 两条都缺 = **宿主进程级漏跑**（OpenClaw 进程当时不在位）→ 当场手动 `openclaw cron run be2b1e10` 补跑，不等下一个 21:30。
  - 有条目但 0 commit = 才查选片规则（R33 的 10/30 属此类：候选集为空 → 空跑）。
- `cron list` 的「Next 2m ago」是**下次触发时刻**，不是「lastRun」；「Last」栏才是上一轮。
- **cron「跑过」≠「产出」**：验收必须看 `git log` 有无新 commit，不能看 `lastRunStatus=ok` / `delivered=true`。
- **压缩失败后不要在原会话续**：长会话 auto-compaction 失败后换新会话再跑（11/04 的 ch4 评审就是这样丢掉的）。
- **派子代理必须交代工具边界**：本机 macOS **没装 `rg`**，子代理调 `rg` 会直接失败（整轮 ~50 秒挂掉）；只许用 `grep` / `sed` / `cat` / `awk` / `wc`。
